# Spellseek — Project Features

## 1. Introduction

Spellseek is a dictionary-based spell-correction application designed to identify misspelled words and suggest possible corrections.

## 2. Core Features

### Spell Checking

Checks whether a word exists in the application's dictionary.

### Spelling Suggestions

Uses edit distance and a BK-tree to find words similar to the entered word.

### Autocomplete

Uses a Trie data structure to suggest words based on the prefix entered by the user.

### Word Ranking

Ranks suggestions using edit distance, word frequency, and alphabetical order.

### Dictionary Lookup

Uses map-based data structures to support efficient word lookup.

### Multiple Interfaces

The project includes a Java command-line version and a browser-based interface built with HTML, CSS, and JavaScript.

## 3. Technologies Used

* Java
* JavaScript
* HTML
* CSS
* Data Structures and Algorithms

## 4. Benefits

* Helps users identify spelling mistakes.
* Demonstrates practical applications of data structures.
* Combines approximate searching with prefix-based autocomplete.
* Provides an opportunity to understand algorithmic efficiency.

## 5. Conclusion

Spellseek demonstrates how data structures and algorithms can be combined to build a useful spell-correction tool.
