**How to use it**

1. Create the `tests` folder in your project root if it doesn't exist.
2. Create `test_dictionary.txt` inside it and paste the contents above.
3. Test the Java version with:

```bash
java Spellseek tests/test_dictionary.txt
```

4. For the browser version, this file is a separate test fixture. Your existing browser interface loads `dictionary.txt` by default, so it will not automatically load `tests/test_dictionary.txt` unless you modify its loading path.

The test dictionary deliberately contains `receive` and `programming` to help test common spelling mistakes such as `recieve` and `progrmming`. Exact suggestions and rankings depend on your implementation and its search-distance settings.
