# Spellseek — Technical Glossary

## 1. Spell Correction
The process of identifying misspelled words and suggesting possible correct alternatives.

## 2. Dictionary
A collection of valid words used by Spellseek to check input and generate suggestions.

## 3. BK-Tree
A tree-based data structure designed to search for items within a specified distance. Spellseek uses it to find words that are similar to the user's input.

## 4. Edit Distance
The minimum number of single-character insertions, deletions, or substitutions needed to transform one word into another.

## 5. Trie
A tree-like data structure that stores words by their character prefixes. It is useful for autocomplete.

## 6. HashMap
A data structure that stores key-value pairs and supports efficient lookups. Spellseek uses map-based lookup for word-related information.

## 7. Autocomplete
A feature that suggests words while a user is typing a prefix.

## 8. Word Frequency
A value representing how frequently a word occurs in the frequency data available to the application. It can help rank suggestions with equal edit distances.

## 9. Candidate Word
A dictionary word considered as a possible correction for the user's input.

## 10. Ranking
The process of ordering candidate suggestions according to rules such as edit distance, word frequency, and alphabetical order.

## 11. Frontend
The part of the application that users interact with. In Spellseek, the browser interface uses HTML, CSS, and JavaScript.

## 12. Backend
The logic that processes input and performs operations behind the user interface. Spellseek also includes a Java command-line implementation.

## 13. JavaScript
A programming language used in the browser version to handle user interactions and spell-correction features.

## 14. Java
A programming language used for the command-line implementation of Spellseek.

## 15. Dictionary-Based Approach
An approach that compares user input against a known vocabulary rather than relying entirely on a language model.

## Conclusion
These terms describe the data structures, algorithms, and technologies that form the foundation of Spellseek.
